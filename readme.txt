The purpose of this project is to create a win10 application to serve one single designated file via a web server. 

- Use tk/tcl for simple user interface.
 - provide a text box for inputting file path and name. 
 - a text box for port (default = 8080)
 - display current ip (all net interfaces)
 - a on/off toggle

When toggle on, create a local web service at given port num, and user can access it at ip:port and see a download link.
